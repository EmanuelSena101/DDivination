# DDivination Base Pack

The surfaces, architectural pieces, props, lights, markers, and token
silhouettes described by `manifest.json` are original procedural models built
from Three.js primitives. They are dedicated to the public domain under
CC0 1.0.

No third-party textures, models, fonts, music, or sound files are included in
this pack. Every listed asset is generated at runtime and the semantic
adventure document does not store rendered meshes.
